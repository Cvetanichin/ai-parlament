# Error Handling Strategy Demo

A small, standalone Vite + React app demonstrating the platform's error
handling patterns in isolation: graceful degradation, offline detection,
user-friendly error messages, and error logging (network failures, API
errors, validation errors). Not part of the Grant Studio Web app
(`apps/grant-studio-web/`) or any governed spec in `docs/` — a scratch
reference implementation, moved here from the repo root for consistency
with the rest of the monorepo's `apps/*` layout.

```bash
npm install
npm run dev
```
